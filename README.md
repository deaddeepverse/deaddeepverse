### Welcome to my corner of GitHub — I'm deaddeepverse 👋

I build mobile apps with Flutter and React Native, mostly trying to make interfaces that feel less like forms and more like something you'd actually want to touch. Lately I've been drawn to offline-first architecture, the kind that assumes the network will let you down and plans accordingly. Dart and TypeScript are my usual tools, Firebase sits behind most of it, and I spend a lot of time thinking about how a transition or animation can carry meaning instead of just being decoration.
